# Bostak Inmobiliaria — Rediseño Web

Rediseño moderno, limpio y profesional para el estudio inmobiliario independiente **Bostak Inmobiliaria** (Bilbao).

## Estilo y Marca

- **Fondo:** `#FFFFFF`
- **Texto principal:** `#111111` / `zinc-950`
- **Acento corporativo:** `#238580` (Teal)
- **Tipografía:** Inter (`next/font/google`)
- **Estética:** Limpia, editorial, sin elementos superfluos y con fotografías reales de las oficinas y el equipo.

## Páginas y Rutas

1. **Inicio (`/`):** Hero con foto suelta y degradado suave, destacados en venta y alquiler, pilares de valor, sección corporativa de confianza y reseñas reales de clientes en Google.
2. **Inmuebles (`/inmuebles-venta-alquiler/`):** Catálogo de inmuebles reales con filtro interactivo en cliente (ciudad, zona, tipo, categoría, rango de precio, habitaciones, baños y m²).
3. **Conócenos (`/conocenos/`):** Presentación del equipo de 5 profesionales (Gabriel, Alberto, Maitane, Maite, Arkaitz) con sus fotografías reales y relato de origen.
4. **Oficina Técnica (`/oficina-tecnica/`):** Servicios especializados en urbanismo, licencias de apertura, cambios de uso, licencias turísticas y soporte técnico.
5. **Contacto (`/contacto/`):** Formulario directo, datos reales de la oficina en Zumalacárregui 115 (Begoña, Bilbao), teléfono, email y mapa interactivo.

## Stack Tecnológico

- **Framework:** Next.js (App Router)
- **Lenguaje:** TypeScript
- **Estilos:** Tailwind CSS
- **Iconografía:** Lucide React
- **Gestor de paquetes:** pnpm

## Instalación y Desarrollo

```bash
# Instalar dependencias
pnpm install

# Servidor de desarrollo
pnpm dev

# Construcción para producción
pnpm build
```
